세포막 지질의 종류와 막 비대칭성

세포막은 똑같은 인지질이 죽 늘어선 막일까, 아니면 여러 종류의 지질이 서로 다른 쪽에 배치된 구조일까?

3D 화면을 불러오지 못했습니다. 브라우저에서 WebGL이 꺼져 있거나 지원되지 않습니다. 최신 Chrome · Edge · Safari에서 다시 열어 주세요.

핵심 개념

  • 세포막은 균일한 막이 아니다. 여러 종류의 지질이 섞여 있다.
  • 막 지질은 종류에 따라 선호하는 leaflet(층)이 다르다 — 막 비대칭성.
  • PS의 바깥 노출은 세포 상태 변화를 알리는 중요한 신호가 될 수 있다.
  • 콜레스테롤은 인지질 사이사이에 삽입되어 막의 유동성과 질서를 조절한다.

이것을 확인해 보세요

  1. 지질 하나를 클릭하면 원자 단위 3D 구조가 열리고, 거기서 2D 구조식과 번갈아 볼 수 있다.
  2. 머리(head)는 물과 닿는 바깥쪽, 꼬리(tail)는 서로 마주 보고 안쪽에 모인다.
  3. 바깥층에는 PC · SM이, 안쪽층에는 PE · PS · PI가 상대적으로 많다.
  4. PIP2는 양은 적지만 안쪽층에만 있고, 모듈 2의 주인공이 된다.
  5. 콜레스테롤은 인지질을 밀어내지 않고 틈에 끼어 들어간다.

※ 여기 표시한 조성은 동물 세포 원형질막의 대표적 경향을 단순화한 것입니다. 실제 조성은 세포 종류, 소기관 막의 종류, 세포의 상태에 따라 달라지며 고정된 비율이 아닙니다.

세포막 인지질과 PIP2 신호전달

PIP2 하나가 잘리면 왜 서로 다른 두 신호 분자가 생기고, 왜 하나는 막에 남고 하나는 세포질로 퍼질까?

    생리학적 확장 — 바소프레신 V1a

    지금 보고 있는 것은 바소프레신이 V1a 수용체에 결합하는 경우의 대표적인 신호전달 예시입니다. 바소프레신의 모든 작용이 이 경로를 쓰는 것은 아닙니다.

    막의 작은 지질 하나를 자르는 반응이 어떻게 세포 전체의 행동 변화로 이어질까?

    1. 신호 물질(ligand) — 혈액을 타고 온 바소프레신
    2. 수용체(receptor) — 원형질막의 V1a (GPCR)
    3. 신호 전달(transduction) — Gq/11 → PLCβ
    4. 2차 전령(second messenger) — PIP2에서 잘려 나온 IP3와 DAG, 그리고 ER에서 나온 Ca2+
    5. 단백질 활성화 — Ca2+–칼모듈린 → MLCK (그리고 병렬로 DAG + Ca2+ → PKC)
    6. 세포 반응(cellular response) — 미오신 경쇄 인산화 → 평활근 수축 → 혈관 수축

    ※ 수축의 주된 경로는 Ca2+ → 칼모듈린 → MLCK → 미오신 경쇄 인산화입니다. PKC는 DAG와 Ca2+에 의해 활성화되는 병렬 가지로, 여러 표적 단백질을 인산화해 수축 신호와 다른 세포 반응을 함께 조절합니다. PKC가 MLCK를 직접 켜는 것이 아닙니다.

    핵심 개념

    • PIP2는 막 안쪽 leaflet에 존재하는 phosphoinositide이다.
    • PLC는 PIP2를 잘라 DAG와 IP3를 만든다.
    • DAG는 소수성 꼬리를 그대로 가지므로 막에 남는다.
    • IP3는 인산기가 많아 친수성이 커서 세포질로 퍼진다.
    • 막 지질은 구조물일 뿐 아니라 신호전달 분자이기도 하다.

    이것을 확인해 보세요

    1. PIP2의 인산기가 세포질 쪽을 향하고 있는지 확인한다.
    2. 잘린 뒤 꼬리를 가진 쪽과 인산을 가진 쪽이 각각 어디로 가는지 본다.
    3. IP3가 ER까지 가서 Ca2+ 통로를 여는 흐름을 따라간다.
    4. DAG와 Ca2+가 함께 있을 때 PKC가 막에서 활성화된다.

    ※ 여기 보여 주는 흐름은 Gq–PLC-beta 계열의 대표적인(canonical) 경로 예시를 단순화한 것입니다. PLC와 IP3 수용체에는 여러 아형이 있고, 세포 종류에 따라 반응의 세부 내용은 달라집니다.

    주의 — V1a와 V2는 다른 경로입니다. 여기서는 V1a 수용체의 Gq–PLCβ 경로를 보여 줍니다. 신장 집합관에서 물 재흡수를 증가시키는 바소프레신 V2 수용체는 Gs–adenylyl cyclase–cAMP–PKA 경로를 주로 사용하며, AQP2의 막 삽입을 촉진합니다. "바소프레신 = PIP2 경로"라고 일반화하지 않도록 주의하세요.

    지방산 베타산화 (β-oxidation)

    지방산은 왜 2탄소씩 잘려 나가면서 acetyl-CoA를 만들까? 그리고 왜 하필 β 탄소일까?

    3D 화면을 불러오지 못했습니다. 브라우저에서 WebGL이 꺼져 있거나 지원되지 않습니다. 최신 Chrome · Edge · Safari에서 다시 열어 주세요.

    드래그 = 회전 · 캔버스를 한 번 클릭한 뒤 휠 = 확대/축소 · 장면은 미토콘드리아 기질(matrix) 안입니다.

      현재 단계

      지금까지의 결과 C16 acyl-CoA

      0cycle
      0acetyl-CoA
      0NADH
      0FADH2

      한 cycle이 끝날 때마다 사슬은 탄소 2개가 짧아집니다.

      C16 (palmitoyl-CoA) 예시 계산

      • 사슬을 8개의 2탄소 조각으로 나누려면 자르는 횟수 = 7 cycle
      • acetyl-CoA 8개 · NADH 7개 · FADH2 7개
      • 일반식: 짝수 탄소 포화 지방산 Cn → cycle n/2 − 1, acetyl-CoA n/2

      보조 정보: 산화적 인산화까지 더하면 흔히 쓰는 교과서 값으로 약 106 ATP에 해당합니다 (acetyl-CoA 8×10 + NADH 7×2.5 + FADH2 7×1.5 − 활성화에 쓴 2). P/O 비 값은 교재마다 다릅니다.

      핵심 개념

      • 지방산은 먼저 활성화되어 fatty acyl-CoA가 된 뒤 대사에 들어간다.
      • 베타산화는 미토콘드리아 기질에서 일어난다.
      • 한 cycle = 산화 → 수화 → 산화 → 절단의 반복이다.
      • 매 cycle마다 acetyl-CoA 1개가 떨어지고 사슬은 2탄소 짧아진다.
      • 매 cycle마다 FADH2 1개, NADH 1개가 만들어진다.

      이것을 확인해 보세요

      1. 카르보닐 탄소(C1)를 기준으로 α(C2), β(C3)를 세는 방법을 확인한다.
      2. 산화가 β 탄소에 집중되는 이유(C–C 결합을 끊기 쉬운 상태로 만든다)를 본다.
      3. 잘려 나가는 조각이 항상 탄소 2개임을 확인한다.
      4. 남은 사슬 끝에 새 CoA가 붙어 곧바로 다음 cycle로 들어간다.

      ※ 그림은 짝수 탄소 포화 지방산(palmitate, C16)을 예로 든 교육용 단순화입니다. 불포화 지방산이나 홀수 탄소 지방산은 추가 효소가 더 필요합니다. 지방산의 활성화는 세포질 쪽에서 일어나고, 긴 사슬 acyl 그룹은 카르니틴 셔틀을 거쳐 기질로 들어옵니다.
