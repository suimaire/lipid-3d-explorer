완료 보고

1. 수정 전 진단뒤쪽 근섬유막과 내부 막의 입자가 경쟁했습니다. T소관 입구는 겹친 머리들로 중심이 막힌 듯 보였고, triad 중앙도 찬 기둥처럼 보일 여지가 있었습니다. 접합 틈은 분리되어 있었지만 강조가 약했습니다.

2. 변경 파일scripts/core/cell-interior.js, scripts/core/curved-bilayer.js, scripts/modules/membrane.js, index.html, styles/app.css, README.md, 이번 QA 보고서와 캡처. 기존 검사 스크립트는 수정하지 않았습니다.

3. Overview먼 막에 카메라 깊이 기반 대비 감소를 적용하고, far 지질 기호 폭을 0.82 → 0.76으로 줄였습니다. 근섬유막의 대비와 근원섬유 opacity(0.16 → 0.10)를 낮췄습니다. 모든 막의 머리와 두 꼬리는 유지합니다.

4. T소관 입구 / lumen좁아지는 funnel 안쪽 둘레의 표본 수와 내강 쪽 기호 폭을 줄였습니다. 카메라 각도, 안쪽 벽의 대비, 물 표식 크기를 조정해 중심 빈 공간을 드러냈습니다. 내강 라벨은 입구 목 부분을 가리킵니다.

5. Triad 기본 화면관찰창을 조금 넓히고 카메라 기울기를 조정했습니다. 뒤쪽 T소관 벽의 대비를 낮춰 위쪽 빈 내강과 양옆 SR 사이의 두 접합 틈이 함께 드러납니다.

6. Triad detail두 cytosolic leaflet 사이를 화면 중심에 맞추고 접합 틈 라벨을 추가했습니다. 반대편 SR의 가장자리와 주변 대비를 줄였습니다. 막 중심면·두께·접합 틈의 기하학적 크기는 바꾸지 않았습니다.

7. UI / 설명 문구“세포 내부” → “세포 속 막 구조”. 보조 문구는 “응용 예시 · 골격근 섬유에서 본 막과 구획화”. 첫 네 문장에 sarcolemma의 이중층, T소관 함입과 세포외 연결, 독립 SR, 융합하지 않는 triad를 순서대로 설명합니다. NMJ는 접힌 보조 관찰에 유지합니다.

8. 성능막의 InstancedMesh 8개와 전체 mesh 14개를 유지했습니다. draw call은 overview 11회 / triad 10회로 동일합니다. 지질 표본과 렌더 부품 수는 소폭 감소했습니다. 깊이 대비 처리는 기존 막 재질에만 적용합니다.

9. Desktop / mobile 시각 QA필수 6개 화면을 실제 Chrome에서 캡처하고 직접 검토했습니다. 1440px desktop, 390px mobile, 추가 320px 화면에서 라벨·컨트롤·가로 넘침을 확인했습니다. 화면별 전후 비교는 아래에 있습니다.

10. 회귀 검사수정 전과 후 모두 브라우저 29개 검사 PASS, 각 35개 캡처. check-interior, check-cell, check-molecules PASS. Whole Cell, 막 patch, 7종 지질 3D/2D, PS·비대칭성, 터치 확대, reduced-motion, Module 2/3 통과. 브라우저 오류 0개.

11. 남아 있는 한계교육용 입자 표본 모델이라 확대에서는 머리들이 여전히 촘촘합니다. 입구의 빈 공간은 작으며 임의 회전 각도에서는 안쪽 벽에 가려질 수 있습니다. 크기·밀도·절개는 실측 표현이 아닙니다. 모바일은 브라우저 기기 모사이며 실물 기기 검증과 2~3초 인지 시간의 사용자 실험은 하지 않았습니다.

Overview — 앞뒤 대비와 막의 연결 형태

뒤쪽도 입자로 남기면서 대비를 낮췄습니다. 구조를 삭제하거나 면으로 대체하지 않았습니다.

T-tubule — 입구 중심의 빈 공간

중앙의 빈 영역과 그 앞뒤의 파란 수용성 공간 표식을 확인할 수 있습니다. 관벽과 함입 경계는 같은 곡면입니다.

Triad — 가운데 빈 T소관과 양옆 SR

T소관 위쪽의 빈 내강이 더 크게 드러납니다. 양쪽 접합 틈과 개별 지질의 색 체계는 유지했습니다.

Triad detail — 융합하지 않는 두 막 사이의 틈

두 막 사이를 중심에 두고 틈을 가리킵니다. 실제 곡면 사이 거리는 그대로이며, 기존 입자 기호 폭의 미세조정만 반영되었습니다.

시각 판정

  • PASS — Overview에서 입자보다 연결 형태가 먼저 읽히고 복잡도가 낮아짐.
  • PASS — T소관 입구 중심의 빈 공간과 세포외 표식 연결이 더 잘 드러남.
  • PASS — Triad 중앙의 hollow 구조와 두 접합 틈이 동시에 보임.
  • PASS — Detail에서 접합 틈, 마주 보는 cytosolic 머리, 두 막의 독립성이 한 화면에 드러남.
  • PASS — Myofibril과 기본 비표시 NMJ보다 막이 시각적 중심을 유지함.
  • PASS — Bilayer 방향·함입 경계·내강·독립 SR·gap 검사 유지.
  • PASS — 390px / 320px에서 컨트롤 가로 넘침 없음, 모바일 확대·회전과 스케일 이동 정상.

시각 판정은 캡처와 로컬 미리보기의 직접 검토 결과입니다. 사용자 실험 결과를 뜻하지 않습니다.
