# 과학적 내용과 교육용 단순화 정리

수업에서 학생 질문이 나왔을 때 바로 답할 수 있도록, 이 페이지가 **무엇을 단순화했고 무엇은 지켰는지**를 정리했습니다.

---

## 모듈 1 — 세포막 지질과 막 비대칭성

### 지킨 것

| 항목 | 페이지에서의 표현 |
| --- | --- |
| 지질 이중층 | 머리는 수용액 쪽, 소수성 꼬리는 서로 마주 보며 안쪽 |
| PC | 포스포콜린 머리, 쌍성 이온(알짜 전하 ≈ 0), **바깥층에 상대적으로 많음** |
| PE | 포스포에탄올아민 머리, 쌍성 이온, **안쪽층에 상대적으로 많음**, 머리가 작아 원뿔에 가까움 |
| PS | 포스포세린 머리, **알짜 음전하**, 건강한 세포에서는 **거의 안쪽층에만** |
| PI | 이노시톨 고리 머리, 알짜 음전하, **안쪽층** |
| PIP2 | 이노시톨 4,5-이인산 머리, 강한 음전하, **안쪽층에만**, 양은 매우 적음 |
| SM | **스핑고신 골격**(글리세롤이 아님) + 포스포콜린 머리, 쌍성 이온, **바깥층에 상대적으로 많음** |
| 콜레스테롤 | −OH 하나뿐인 작은 머리 + 단단한 네 고리 골격, 인지질 사이에 삽입, 양쪽 leaflet 모두 |
| 비대칭성 유지 | 저절로 유지되는 것이 아니라 flippase 등이 **ATP를 써서** 만들어 냄 |
| PS 노출 | flippase 활성 저하 + scramblase 활성화로 일어남. 식세포가 알아보는 **중요한 신호 중 하나** |

### 단순화한 것

- **조성 비율.** 화면에 배치한 지질 개수(바깥층 PC 17 · SM 11 · PE 8 / 안쪽층 PE 13 · PC 9 · PS 8 · PI 4 · PIP2 2)는
  "어느 쪽에 무엇이 많은가"라는 **경향**을 보여 주기 위한 값입니다. 실제 조성은 세포 종류, 막의 종류
  (원형질막 / ER / 미토콘드리아 막), 세포 상태에 따라 달라집니다. 페이지 하단에도 같은 주석을 넣었습니다.
  - 특히 PIP2는 실제로 막 인지질의 약 1% 수준인 **소수 성분**입니다. 화면에서도 2개만 배치했습니다.
- **전체 막의 분자 모양.** 막 전체에 놓인 수백 개의 지질은 원자 수준이 아니라
  `머리(구) + 인산(작은 구) + 골격(짧은 막대) + 꼬리(막대 2개)`로 이루어진 도식(coarse-grained) 모델입니다.
  꼬리의 꺾임은 불포화 여부를 암시하는 정도로만 표현했고(SM은 곧게), 실제 탄소 수·이중결합 위치를
  나타내지 않습니다. 성능과 가독성을 위한 의도적인 계층 설계이며, **지질 하나를 클릭하면 그 분자만
  원자 단위(atomistic) 구조로 바뀝니다.**
- **콜레스테롤 개수.** 실제 원형질막에서 콜레스테롤은 인지질과 거의 비슷한 몰 비까지 올라갈 수 있지만,
  화면에서는 "인지질 사이 틈에 끼어 있다"는 배치가 보이도록 12개만 넣었습니다.
- **PS 노출 애니메이션.** 개별 PS가 막을 가로질러 넘어가는 경로를 호(arc)로 단순화했습니다.
  실제로는 scramblase가 매개하는 양방향 이동이며, 특정 분자 하나의 궤적을 뜻하지 않습니다.

### 원자 단위 3D 구조에서 쓴 대표 분자 (representative species)

지질 하나를 클릭하면 나오는 원자 단위 3D 모델은 `scripts/core/molecules.js` 가 표준 결합 길이·결합각·
이면각으로 좌표를 직접 계산해 만듭니다. PC·PE·PS·PI·PIP2·SM 은 **고정된 단일 분자가 아니라 지방산 조성이
다양한 class** 이므로, 아래의 **대표 분자 하나**를 골라 그렸습니다. 화면 오른쪽 패널에도 어떤 대표
구조인지와 "실제 생체막에서는 사슬의 길이·불포화도가 다양하다"는 주석을 함께 표시합니다.

| 지질 | 대표 분자 | 아실 조성 | 화학식 |
| --- | --- | --- | --- |
| PC | POPC · 1-palmitoyl-2-oleoyl-sn-glycero-3-phosphocholine | 16:0 / 18:1 cis-Δ9 | C42H82NO8P |
| PE | POPE · …-3-phosphoethanolamine | 16:0 / 18:1 cis-Δ9 | C39H76NO8P |
| PS | POPS · …-3-phospho-L-serine | 16:0 / 18:1 cis-Δ9 | C40H76NO10P |
| PI | POPI · …-3-phospho-(1'-myo-inositol) | 16:0 / 18:1 cis-Δ9 | C43H79O13P |
| PIP2 | PI(4,5)P₂ (1-palmitoyl-2-oleoyl 형태) | 16:0 / 18:1 cis-Δ9 | C43H79O19P3 |
| SM | N-palmitoyl-D-erythro-sphingosylphosphorylcholine | d18:1 골격 / 아미드 16:0 | C39H79N2O6P |
| 콜레스테롤 | cholest-5-en-3β-ol | 지방산 없음 | C27H46O |

**아실 조성을 다섯 지질에서 똑같이(16:0 / 18:1) 맞춘 이유**는, 그렇게 해야 PC·PE·PS·PI·PIP2 사이의
차이가 **오직 머리 그룹에서만** 생기는 것이 눈으로 바로 보이기 때문입니다. 실제 몸에서는 PIP2가
**18:0 / 20:4(스테아로일·아라키도노일) 조성**으로 많이 존재한다는 점을 패널에도 적어 두었습니다.

#### 원자 단위 모델에서 지킨 것

- 글리세로인지질 5종: 글리세롤 골격 + **에스터 결합** 2개 + 인산 다리 + 각자의 머리 그룹
- PI · PIP2: 의자형 **myo-이노시톨 고리**(2번 −OH만 축방향, 나머지는 적도방향),
  1번 탄소가 인산 다리로 글리세롤과 연결. PIP2는 **4번·5번 탄소에만** 인산이 하나씩 더 붙습니다.
- SM: **스핑고신 골격**(글리세롤이 아님), 지방산은 **아미드 결합**, C3의 −OH, Δ4 **trans** 이중결합
- 콜레스테롤: 6-6-6-5로 **변을 공유해 붙은 네 고리**, 3β−OH, C18·C19 메틸, C5=C6, C17 곁사슬
- 올레오일의 Δ9 이중결합은 **cis** 로 놓아 꼬리가 꺾이는 것이 보이게 했습니다.

#### 원자 단위 모델에서 단순화한 것

- **수소를 그리지 않습니다.** 지질 한 분자의 수소는 80개가 넘어 화면을 가립니다(heavy-atom 표기).
- **좌표는 이상적인 값으로 계산한 것**이지, 실험 구조(X선·NMR)나 에너지 최소화 결과가 아닙니다.
  결합 길이·결합각은 표준값이지만, 사슬이 나란히 눕도록 자유 회전 결합의 이면각을 골라 준
  **하나의 그럴듯한 배좌(conformation)** 일 뿐입니다. 실제 막에서 사슬은 끊임없이 움직입니다.
- 입체중심(sn-글리세롤의 배열, 스핑고신의 2S,3R 등)은 결합 관계만 맞췄을 뿐,
  수소를 생략했기 때문에 화면에서 R/S 를 읽을 수 있는 수준으로 그리지는 않았습니다.
- 전하는 3D 모델에 표시하지 않습니다(2D 구조식과 오른쪽 패널에서 다룹니다).

이 좌표들은 `node scripts/qa/check-molecules.mjs` 로 자동 점검합니다 —
화학식과 원자 수, 결합 길이 범위, 원자끼리 겹침, 에스터/아미드 구분, PIP2의 인 3개,
스테로이드 네 고리의 접합 구조, C=C의 cis/trans 배치를 확인합니다.

### 피한 오개념

- PS가 정상 상태에서 바깥층에 많다고 표현하지 않았습니다.
- 특정 지방산 조합 하나를 그 지질 class의 유일한 구조인 것처럼 제시하지 않았습니다.
- PIP2를 바깥층에 두지 않았습니다.
- 콜레스테롤을 "나쁜 물질"로 서술하지 않았습니다 — 막의 정상 구성 성분이며 유동성·질서를 조절한다고 썼습니다.
- 조성을 고정된 절대 비율로 단정하지 않았습니다.

## 모듈 2 — PIP2 신호전달

### 지킨 것

- PIP2는 **안쪽(세포질 쪽) leaflet**에 있고, 인산이 붙은 머리가 세포질을 향합니다.
- PLC는 **글리세롤과 인산 사이**를 끊습니다. 그 결과
  - 꼬리(acyl chain 2개)를 가진 쪽 → **DAG**, 소수성이 커서 **막에 남습니다**.
  - 인산 3개가 붙은 이노시톨 고리 → **IP3**, 친수성이 커서 **세포질로 확산합니다**.
- IP3는 ER 막의 **IP3 수용체(그 자체가 Ca²⁺ 통로)** 에 결합해 통로를 엽니다.
- Ca²⁺는 ER lumen에 높은 농도로 저장돼 있다가 **농도 기울기를 따라** 세포질로 나옵니다.
- DAG와 Ca²⁺가 **함께** 작용해 PKC를 막에서 활성화합니다.

### 단순화한 것

- **핵심 7단계는 대표 경로 하나만** 보여 줍니다. Gq 결합 수용체 → PLCβ 계열의 canonical signaling을
  교육용으로 단순화한 것이며, 핵심 7단계에서는 수용체·G 단백질 단계를 장면에서 생략했습니다
  (캡션에 "신호가 수용체를 통해 전달되면"으로만 언급). 그 상류를 실제로 보고 싶을 때
  **[생리학적 확장 보기 — Vasopressin V1a]** 로 넘어가면 수용체부터 다시 이어서 봅니다(아래 참조).
- PLC와 IP3 수용체에는 여러 **아형**이 있고 세포 종류에 따라 반응이 다릅니다. 화면에는 하나씩만 그렸습니다.
- IP3 수용체를 소단위 4개의 통로로 도식화했습니다(실제로 4량체인 것은 맞지만, 세부 구조는 아닙니다).
- IP3·DAG의 이후 대사(IP3의 탈인산화, DAG의 재활용 등)는 다루지 않았습니다.
- 분자 크기 비율은 실제 비율이 아닙니다. PIP2는 알아보기 쉽도록 주변 인지질보다 크게 그렸습니다.

### 피한 오개념

- IP3가 막에 남는 것처럼 표현하지 않았습니다.
- DAG가 세포질로 자유롭게 퍼지는 것처럼 표현하지 않았습니다(막 안에서 옆으로만 움직입니다).
- 절단 산물을 반대로 표시하지 않았습니다 — **꼬리 = DAG, 인산 머리 = IP3**.

### 카메라와 재생 속도

- **자동 재생(▶ 재생)** 은 원형질막 · 세포질 · ER이 한 화면에 들어오는 **overview 시점**으로
  약 1초에 걸쳐 부드럽게 이동한 뒤, 재생하는 동안 카메라를 더 움직이지 않습니다.
  학생이 "이 일이 세포의 어디에서 일어나는가"라는 공간 감각을 계속 유지하게 하기 위해서입니다.
  단계별 강조는 카메라 이동이 아니라 **라벨 전환과 아주 작은 scale 강조**로만 합니다.
- **이전/다음 단계·단계 직접 선택** 같은 수동 탐색에서는 예전처럼 단계별로 가까운 시점을 씁니다.
- 자동 재생 중 사용자가 직접 드래그·확대하면 그 시점을 그대로 존중하며, 단계가 넘어가도
  카메라를 overview로 되돌리지 않습니다.
- 재생 속도는 `scripts/modules/pip2.js` 의 `PIP2_TIMING` 한 곳에서 관리합니다.
  한 단계의 길이 = `max(그 단계에서 실제로 만들어진 가장 긴 움직임, minMotion) + hold` 이며,
  기존의 "단계당 3.6초 고정"에 비해 **약 1.5~1.9배(단계당 5.4~6.8초)** 느립니다.
  `prefers-reduced-motion` 환경에서는 이동 시간을 0으로 두고 hold만 남겨,
  움직임 없이도 각 단계의 상태 변화를 확인할 수 있게 했습니다.

## 모듈 2 확장 — 바소프레신 V1a 수용체 (생리학적 예시)

핵심 7단계를 끝까지 본 뒤 **[생리학적 확장 보기 — Vasopressin V1a → 혈관 평활근 수축]** 버튼으로
들어가는 별도 모드입니다. 화면 위쪽에 현재 모드가 항상 표시되고,
**[← PIP2 핵심 과정으로 돌아가기]** 로 언제든 돌아올 수 있습니다.

### 이 확장이 무엇인지 (가장 중요한 전제)

1. 기존 PIP2 애니메이션(핵심 7단계)은 **canonical Gq–PLCβ signaling을 교육용으로 단순화한 것**입니다.
   특정 호르몬 하나를 지정하지 않은 일반적인 예시입니다.
2. 이 확장은 **바소프레신이 V1a 수용체에 결합하는 경우**의 대표적인 Gq/11 signaling 예시입니다.
   "바소프레신이 어떤 수용체에 붙었을 때"라는 조건이 반드시 함께 붙습니다.
3. **바소프레신의 모든 작용이 이 경로를 쓰는 것은 아닙니다.** 페이지에서
   "바소프레신은 PIP2 경로를 쓴다"라고 일반화해 서술하지 않았습니다.
4. 신장 집합관의 **V2 수용체**는 **Gs–adenylyl cyclase–cAMP–PKA** 경로를 주로 사용하며
   **AQP2**의 정단막 삽입을 촉진해 물 재흡수를 늘립니다. V1a의 Gq–PLCβ 경로와 다른 경로입니다.
   이 비교는 설명 패널 아래쪽의 "주의" 박스에도 그대로 넣어 두었습니다.
   이번 버전에서 V2 경로 자체를 3D로 구현하지는 않았습니다.

### 확장 모드에서 지킨 것

- 인과 순서를 지켰습니다. 수용체와 G 단백질은 PLC보다 **상류**이므로,
  핵심 7단계 뒤에 바소프레신을 덧붙이지 않고 **처음부터 다시** 이어서 보여 줍니다
  (vasopressin → V1a → Gq → PLCβ → PIP2 → IP3 + DAG → IP3R → ER Ca²⁺ → …).
- 바소프레신은 **펩타이드 호르몬**이라 막을 통과하지 못하고 표면 수용체를 거쳐야 한다는 점을 명시했습니다.
- V1a는 **7회 막관통 GPCR**로 그렸습니다.
- Gq/11 단계에서 **GDP → GTP 교환 후 Gαq가 Gβγ에서 분리**되어 PLCβ를 활성화한다는 관계를 지켰습니다.
- 혈관 평활근 수축의 **주된 Ca²⁺ 의존 경로**를 다음 순서로 그렸습니다.

  > Ca²⁺ → 칼모듈린 → **MLCK** → 미오신 조절 경쇄(RLC) 인산화 → actin–myosin 상호작용 증가 → 수축

- **PKC는 이 수축 과정의 직렬 상류 효소로 표현하지 않았습니다.** DAG와 Ca²⁺에 의해 활성화되는
  **병렬 가지(branch)** 로 남겨 두고, "여러 표적 단백질을 인산화해 수축 신호와 다른 세포 반응을
  함께 조절한다" 정도로만 설명합니다. PKC → MLCK 화살표는 그리지 않았습니다.
- 마지막 장면에서 다시 넓게 물러나
  ligand → receptor → signal transduction → second messenger → protein activation → cellular response
  라는 계층을 3D 위치와 짧은 라벨만으로 한 번에 복습하게 했습니다.

### 확장 모드에서 단순화한 것

- **G 단백질을 원자 수준으로 그리지 않았습니다.** Gα와 Gβγ를 덩어리(blob)로 두고,
  뉴클레오타이드는 작은 구슬 하나(GDP 회색 → GTP 주황)로만 표현했습니다.
  GAP 활성, GTP 가수분해에 의한 신호 종료, RGS 단백질은 다루지 않았습니다.
- **PLCβ·IP3 수용체·PKC의 아형**은 구분하지 않았습니다.
- **수축 장치는 도식입니다.** 평활근은 골격근 같은 sarcomere가 아니라 dense body에 액틴이 붙는
  구조지만, "액틴이 미오신 위를 미끄러져 세포가 짧아진다"는 관계를 보이기 위해
  미오신 굵은 필라멘트 + 액틴 가는 필라멘트 + 양쪽 dense body 로 단순화했습니다.
  실제 세포 전체의 수축이나 혈관 단면 변화는 3D로 그리지 않고 라벨과 설명으로만 다룹니다.
- **이번 버전에서 일부러 넣지 않은 것**: CPI-17, 미오신 인산가수분해효소(MLCP)와 Ca²⁺ 감작
  (Ca²⁺ sensitization), Rho/Rho kinase 경로, 전압 의존성 Ca²⁺ 통로를 통한 세포 밖 Ca²⁺ 유입.
  수업용으로는 주된 Ca²⁺–CaM–MLCK 축 하나를 분명히 보는 편이 낫다고 판단했습니다.
- **Ca²⁺ 개수**는 실제 이온 수가 아닙니다. ER → 세포질의 이동 **방향**이 보이는 정도만 그렸고,
  그중 4개만 칼모듈린에 결합하는 것으로 표시했습니다(칼모듈린의 Ca²⁺ 결합 자리가 4개인 것에 맞춘 것이며,
  협동적 결합의 세부는 다루지 않습니다).
- 세포 영역(세포 바깥 / 세포질 / ER lumen)은 아주 옅은 배경 띠와 라벨로만 구분했습니다.
  세포 전체 형태를 3D로 만들지 않았습니다.

### 확장 모드에서 피한 오개념

- 바소프레신을 PLC보다 **하류**에 놓지 않았습니다(7단계 뒤에 덧붙이지 않고 처음부터 다시 시작합니다).
- "바소프레신 = PIP2 경로"라고 일반화하지 않았습니다 — **V1a에 결합하는 경우**로 한정했습니다.
- V1a의 Gq 경로와 V2의 Gs–cAMP–PKA 경로를 섞지 않았고, 둘의 차이를 명시적으로 적어 두었습니다.
- **PKC → MLCK → 수축** 이라는 직렬 사슬로 그리지 않았습니다.

## 모듈 3 — 지방산 β-산화

### 지킨 것

- 지방산은 먼저 **fatty acyl-CoA로 활성화**된 뒤 대사에 들어갑니다.
- β-산화는 **미토콘드리아 기질(matrix)** 에서 일어납니다. 장면 전체를 미토콘드리아 내부로 그렸습니다.
- 긴 사슬 acyl 그룹은 **카르니틴 셔틀**을 거쳐 기질로 들어옵니다(설명 패널 주석).
- 번호 매김: 카르보닐 탄소 = C1, 그다음이 α(C2), 그다음이 β(C3).
- 한 cycle의 4단계:
  1. **산화** — acyl-CoA dehydrogenase, α–β 사이 이중결합 생성(trans-Δ²-enoyl-CoA), **FAD → FADH₂**
  2. **수화** — enoyl-CoA hydratase, −OH가 **β 탄소**에, H가 α 탄소에 (L-3-hydroxyacyl-CoA). 산화·환원 없음
  3. **산화** — 3-hydroxyacyl-CoA dehydrogenase, β의 −OH → 케톤(3-ketoacyl-CoA), **NAD⁺ → NADH**
  4. **절단** — thiolase가 CoA-SH로 **C2–C3 결합**을 끊음 → **acetyl-CoA 1개** 분리, 사슬은 **탄소 2개** 감소
- C16(palmitoyl-CoA): **7 cycle · acetyl-CoA 8 · NADH 7 · FADH₂ 7**.
  일반식 Cₙ(짝수·포화) → cycle **n/2 − 1**, acetyl-CoA **n/2**.
  - 마지막 7번째 cycle에서 C4가 잘려 acetyl-CoA가 **2개** 나오므로 cycle 수보다 acetyl-CoA가 1개 많습니다.
    페이지는 이 마지막 단계를 실제로 애니메이션으로 보여 줍니다.

### 단순화한 것

- **짝수 탄소 포화 지방산만** 다룹니다. 불포화 지방산(isomerase, reductase 추가)이나 홀수 탄소 지방산
  (마지막에 propionyl-CoA)은 다루지 않았습니다. 설명 패널에 명시했습니다.
- 사슬을 탄소 구슬과 막대로 그린 **2.5D 도식**입니다. 수소 원자는 그리지 않았고, 이중결합은 막대 하나를
  덧그려 표현했습니다. 실제 결합 각도·입체 배치를 나타내지 않습니다.
- 각 단계를 촉매하는 효소는 캡션에 이름만 적고 3D로 그리지 않았습니다.
- FAD/NAD⁺는 원반 아이콘으로 표현했습니다. 실제로 acyl-CoA dehydrogenase의 FAD는 효소에 결합해 있고,
  전자는 ETF를 거쳐 전자전달계로 넘어갑니다.
- **ATP 수율**은 기본 화면에 넣지 않고 "C16 예시 계산" 안의 보조 정보로만 표시했습니다
  (acetyl-CoA 8×10 + NADH 7×2.5 + FADH₂ 7×1.5 − 활성화 2 = 약 106). **P/O 비 값은 교재마다 다릅니다.**

### 피한 오개념

- 세포질에서 β-산화가 일어나는 것처럼 보이지 않게 했습니다.
- 매 cycle마다 탄소가 1개 줄어드는 것으로 표현하지 않았습니다 — 항상 **2개**입니다.
- 생성물 개수를 잘못 세지 않습니다. 실제로 반복 재생하면 7 / 8 / 7 / 7 로 끝나는 것을 화면에서 확인할 수 있습니다.
- "β-산화"라는 이름의 이유(β 탄소가 산화되어 α–β 결합이 끊어지기 쉬워짐)를 별도 버튼으로 설명합니다.

## 화학 구조식 (모듈 1 · LEVEL 2)

### 지킨 것

| 지질 | 구조식에서 반드시 맞춘 부분 |
| --- | --- |
| PC | 글리세롤 골격 + **에스터** 결합 acyl 2개 + 인산 + **콜린** |
| PE | 글리세롤 골격 + **에스터** 결합 acyl 2개 + 인산 + **에탄올아민** |
| PS | 글리세롤 골격 + **에스터** 결합 acyl 2개 + 인산 + **세린**(−COO⁻ 때문에 알짜 음전하) |
| PI | 글리세롤 골격 + 인산 + **myo-이노시톨 고리**(1번 탄소로 연결) |
| PIP2 | PI 구조 + 이노시톨 **4번·5번 탄소**의 인산 2개 = PI(4,5)P₂ |
| SM | **스핑고신 골격(글리세롤 아님)** + **아미드** 결합 지방산 + 포스포콜린 |
| 콜레스테롤 | 六-六-六-五 네 고리 융합 + 3-OH + C5=C6 + 각 메틸 2개 + 갈래 곁사슬 |

- 글리세로인지질의 지방산은 **에스터**, 스핑고미엘린의 지방산은 **아미드**로 명확히 구분해 그렸습니다.
- 인산은 글리세롤의 sn-3 위치에 붙고, 머리 그룹은 그 인산을 통해 연결됩니다.

### 단순화한 것

- **모두 class 수준의 일반화 구조**입니다. acyl chain을 `R₁` / `R₂`(SM은 `R`)로 두어,
  특정 지방산 하나가 그 지질의 유일한 구조인 것처럼 보이지 않게 했습니다.
- 머리 그룹 가운데 콜린·에탄올아민·세린은 축약 구조식(condensed formula)을 색 칩 안에 적었습니다.
  위치 번호가 의미를 갖는 이노시톨 고리만 실제 고리로 그렸습니다.
- 입체 배치(스테레오켐)는 표시하지 않았습니다. 콜레스테롤의 3β-OH도 방향 없이 −OH로만 그렸습니다.
- 수소 원자는 골격에 필요한 경우(H₂C, HC)만 적었습니다.
- 색은 3D 모델의 부위와 맞춘 **학습용 구분**이며 화학적 표준 색이 아닙니다. 화면에도 같은 문구를 넣었습니다.

## 공통

- 소수성 상호작용을 "특별히 강한 결합"으로 설명하지 않았습니다. 꼬리끼리 **모여 있는 배치**로만 보여 줍니다.
- 모든 3D 모델은 크기·비율이 실제 값이 아닙니다. 구조의 **차이**를 알아보게 하는 것이 목적입니다.
- 색은 종류를 구분하기 위한 임의의 배색이며 실제 색이 아닙니다.
